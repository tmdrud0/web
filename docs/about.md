이 블로그는 온라인 저지 서비스를 만들면서 겪은 성능 병목, 복구 설계, 랭킹 조회 최적화를 정리하는 공간이다.

중심 관심사는 세 가지다.

- 대량 트래픽에서 쓰기 경로를 어떻게 버티게 만들 것인가
- Redis 같은 파생 상태를 어떻게 안전하게 복구할 것인가
- 랭킹처럼 깊은 페이지에서 무너지는 조회를 어떻게 다시 설계할 것인가

포스트는 이 저장소의 실험 기록과 포트폴리오 문서를 바탕으로 정리했다.
